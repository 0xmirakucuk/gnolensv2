# Course materials (local only)

Put lecture notes, slides and past exams here, one folder per course:

```
content/materials/math/   lecture notes for 30400
content/materials/micro/
content/materials/cs/
```

Everything in this folder except this README is **git-ignored**: the repository is public and
course materials are usually copyrighted, so they must never be committed. Only files a human
places here are read (see CLAUDE.md), and ingestion (M4) will read them from this folder.
